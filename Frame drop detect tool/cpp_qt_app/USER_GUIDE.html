Overview

Frame Check reads the counter printed inside each frame. It does not use a video's container frame number as the counter.

Use Analyze frame numbers to find gaps and duplicates. For videos, frames are checked in playback order and are numbered from zero in the report. Image folders are read in sorted filename order. Use Scan image health for a separate check that verifies image files can be opened.

Before you start

  • For image sequences, put supported .png, .jpg, .jpeg, or .bmp files in one folder.
  • For video analysis, use an .avi, .mp4, or .mov file. The video codec must be available to the decoder.
  • Make sure the counter is visible and legible in the first image or video frame. Select a crop that includes the counter in the same position in every frame.
  • Tesseract's English OCR data (eng.traineddata) must be available to the installed application.

Your source media is not changed. Frame Check reads the selected images or video and writes a separate text report. Existing reports are preserved; a revision suffix is used when a report name already exists.

Analyze frame counters

  1. Select Image folder... or Video file... and choose the source.
  2. Choose Select counter area... and mark the digits on the first frame, or enter the crop coordinates directly.
  3. Select Preview crop to check that the crop contains the whole counter and little unrelated detail.
  4. Select Analyze frame numbers. The progress bar and status line show the scan progress.
  5. Review the summary and full report in the lower text area, then open the saved report if you need to search or share it.

The coordinates are pixel positions in the source frame: x1 is the left edge, x2 the right edge, y1 the top, and y2 the bottom. Keep the right and bottom values greater than the left and top values.

Uncheck Show crop box to hide the coordinates panel when more space is useful. The crop values are retained.

Select a counter area

In the selection dialog, drag a rectangle around the counter. The rectangle must include all counter digits. Avoid including subtitles, logos, or other changing text that may confuse OCR.

After confirming, the rectangle is converted to the four coordinate fields and the crop preview is updated. If the video counter moves between frames, choose a crop that covers its full range of movement.

Understand the results

The report shows the number of frames processed, OCR-recognized counters, detected duplicates, missing counter values, and any unresolved issues. For a video, a missing value may include an estimated time and the next observed frame to help you navigate the source.

Report itemMeaning
Total dropped framesNumber of missing counter values inferred from the sequence, not a count of physical video frames removed.
Dropped frame numbersMissing counter values, compacted into ranges when possible.
Duplicated framesAdjacent frames or sorted images that show the same counter value.
Unresolved OCR/sequence issuesFrames without a usable counter or transitions that cannot safely be classified.
Incomplete analysisOne or more unreadable or suspect transitions make the drop/duplicate totals provisional.

OCR is not infallible. Review unexpected gaps against the original frames. Backwards counters, isolated OCR spikes, and unreadable frames are reported as unresolved instead of being silently corrected.

Reports are saved beside the selected video or inside the selected image folder. Frame analysis uses frame_check_results.txt and revision names such as frame_check_results_rev1.txt. Video frame indices in report details are zero-based. Estimated timestamps are approximate when decoder timing is unavailable, especially for variable-frame-rate video.

Scan image health

Choose an image folder and select Scan image health. This check attempts to load each supported image and reports files that fail to load or decode. It does not read frame counters and does not support video files.

The report is saved in the selected folder with a name such as file_tester_report.txt. Existing reports are kept; later scans receive a revision suffix.

Troubleshooting

No input or first frame cannot be read

Confirm the selected folder or file still exists. For image folders, check that they contain PNG, JPG, JPEG, or BMP images. For video, confirm the codec can be decoded by the installed version.

Crop preview is wrong or OCR finds unexpected gaps

Reselect the crop around the counter, verify the preview, and make sure the digits are legible in the source. If the counter changes position, enlarge the crop enough to include it throughout the sequence. Check unexpected results against the original frames.

Totals are provisional

Read the unresolved section of the report. Unreadable frames and suspect transitions prevent Frame Check from making a reliable drop or duplicate determination across those transitions.

Report not found where expected

Frame reports are saved in the selected image folder, or beside the selected video. If the base report already exists, look for a filename ending in _rev1, _rev2, and so on.
