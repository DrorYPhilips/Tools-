README for Sample6A

This sample requires the presence of the live555 header files and static link libraries.
The latest live555 source package can be obtained from http://www.live555.com/liveMedia/

Copy the contents of the downloaded live directory into the live directory in the THIRDPARTY/LIVEMEDIA directory.

Build the live libraries according to recommended instructions.

For more information, see readme.txt in the THIRDPARTY/LIVEMEDIA directory.
